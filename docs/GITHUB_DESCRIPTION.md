# GitHub repository description

CodeBook is a free, open-source, offline technical book and system bible editor for Windows. Write programming books and game design documents with nested sections, topic icons, progress tracking, rich text, syntax-highlighted code, ChatGPT-friendly paste, dark mode, autosave, and Markdown/HTML export.
