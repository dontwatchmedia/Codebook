# GitHub repository description

CodeBook is a free, open-source offline writing app for Windows: technical books, game design documents, and nested system bibles. Rich text, Markdown import, highlighted code, smart search, progress icons, a zoomable outline, autosave, and formatted PDF, Markdown, and HTML export.
