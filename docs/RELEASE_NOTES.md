# CodeBook 0.1.0 — Technical book writing for Windows

The first public CodeBook release brings books, rich text, and code examples into one offline Windows writing app.

## Download

- **CodeBook.exe** — the current portable Windows executable.
- **CodeBook-0.1.0-Windows.zip** — the same executable with a quick-start guide, README, validation notes, MIT license, and SHA-256 checksum.
- **CodeBook.exe.sha256** — checksum for the executable.

Download the EXE directly, or extract the ZIP and double-click CodeBook.exe. No Node.js, Rust, login, or development server is needed to use it. Requires 64-bit Windows 10/11 and Microsoft Edge WebView2. The executable is unsigned.

## Included

- Book library, parts, chapters, drag reordering, and metadata.
- Rich-text editing, images, tables, lists, links, and inline code.
- Syntax-highlighted code blocks, language selection, filenames, line numbers, and copy controls.
- Formatted HTML/Markdown paste and native CodeBook clipboard support.
- Dark mode with a visible moon/sun switch and a preference that survives restarting.
- Local autosave, atomic file writes, crash recovery, and backup snapshots.
- Search, private notes, chapter status, word goals, and focus mode.
- Markdown/HTML export and portable `.codebook` project import/export.

This release contains only the latest tested build, including the dark-mode update. No previous executable versions or user manuscripts are included.

PDF, EPUB, DOCX, cloud sync, AI, and collaboration are not included in this early release. See the README and VALIDATION.md for details.
