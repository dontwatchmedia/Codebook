CODEBOOK 0.2.10 — BOOKS AND SYSTEM BIBLES

Extract the ZIP, then double-click CodeBook.exe.

No account, internet connection, Node.js, or Rust is needed to write.
Requires 64-bit Windows 10/11 and Microsoft Edge WebView2.

Open the Learning C++ sample, choose New book, or choose New system bible.
Drag the left panel's right edge to make the outline wider or narrower.
The width is remembered after restarting. Double-click the divider to reset.
You can also focus it and press Left/Right, Shift for bigger steps, or Home/End.
The project title now sits beside Your bookshelf above compact outline rows.
Hold Ctrl and use the mouse wheel over the left panel to change its text
and emoji sizes from 80% to 200%, without changing the writing zoom.
The minus/plus controls also resize outline text; click the percentage to reset.
Expand all sections and Collapse all sections control all nested branches.
Click Tools to hide or show the lower add/import/progress/help area.
Outline zoom, the Tools choice, and collapsed branches are remembered locally.
Total words and a page counter remain visible even when Tools is collapsed.
Compact writing is the default: less padding, tighter gaps, more room for text.
Use the Compact / Original spacing choice above the editor to switch views.
This changes the display; your saved typography and exports remain intact.
Use Writing zoom below the editor to match your source's display scale.
For a browser or Google Docs at 80%, choose 80%. Use 100% to reset.
Zoom scales pasted text too and is remembered when the app restarts.
Choose Light, White, Sepia, Dark, Midnight, Ocean, Rose, or Lavender in Color theme.
White uses pure white paper, gray panels, and blue accents like Google Docs.
Compact mode also tightens divider gaps in existing writing.
Double-click a left-hand title (or press F2) to rename it. Enter saves,
Escape cancels, and clicking away saves a valid name. Click the emoji
button beside a section number/icon to search 3,773 offline emoji.
Search names, keywords, partial words, or paste an emoji. Try done, wip,
dragon, farming, or dark skin scientist. Filter by category and choose
Show more emojis to browse. Down enters the grid, arrows move, Enter
selects, and Escape closes. Custom emoji and Clear remain available.
A system bible starts with an Overview. Select a section and choose
Add child section to build systems, sub-systems, and features below it.

Choose Import chapters / Import sections to select multiple .md or .markdown
files. Each becomes an editable chapter using Google-style Arial typography.
Headings, lists, emphasis, links, tables, and code structure are preserved.
The first H1 becomes its title, or the filename is used when there is no H1.
You can also drag Markdown files from File Explorer onto an outline row.
Drop in its middle to add children; top/bottom edges insert siblings.
Drag chapter titles the same way to reorder or nest entire branches.
Use Move to top level to promote a branch. Child writing and metadata stay
attached. Task checkboxes retain their states as text markers.
Local companion images retain caption/path references; they are not embedded.

Already pasted Markdown that still shows ## headings or **bold** markers?
Click Format Markdown in the writing toolbar. Select text to convert only
that passage, or leave nothing selected to format the chapter or section.
The converted text uses the same Google-style typography as Markdown imports.
Undo restores the original text.

Press Ctrl+F or click Search to find writing. Results start in the current
chapter or section, then continue through the project and wrap around.
Full section paths, match counts, and snippets help locate nested writing.
Matches are highlighted; the current match has a distinct highlight.
Enter goes to the next match and Shift+Enter goes to the previous one.
Find keeps its query and each section's match as you switch sections.
Replace and Replace all affect ONLY the current chapter or section.
Use Undo to restore a replacement. Ctrl+Shift+F opens advanced project
search with text, code, and tag filters.

Switching sections remembers each section's scroll position and selection.
Reopening a project resumes its last visited section. These local reading
preferences are separate from project exports; a forced app shutdown can
lose the latest position.

Use Section icon and Progress in the details panel to mark each section.
Progress choices are Not started, In progress, Complete, Blocked, and
On hold. Each section's progress is independent.

Use Parent section to move an entire branch. Drag to reorder siblings,
or use the move actions. Deleting a parent keeps its child sections and
their writing one level higher.

To change an existing book into a system bible, open its settings beside
the project title and change Project type. Writing and hierarchy stay intact.

Your projects are saved in your Windows app-data folder, not beside the EXE.
Preferences shows the exact location. Moving the EXE does not move your
library. Use Export > CodeBook project to back up or transfer a complete
project, including its hierarchy, icons, progress, notes, and images.
Markdown and HTML exports preserve a system bible's nested organization.

Choose Export > PDF > Preview PDF, or click the outline's page counter,
for formatted PDF output with selectable text, code, tables, and images.
Choose Letter or A4 paper with 0.55-inch margins. Options include the project
title, starting each chapter/section on a new page, and page numbers.
Compact spacing is checked by default for the tighter Google Docs-style gaps.
Uncheck it to retain original document spacing; font sizes and formatting remain.
In the Windows app, wait for preparation and choose Save PDF.
The live outline page count is labeled as an estimate until a native PDF is
prepared. That prepared PDF supplies an exact count for its content and settings.
Editing the project or changing settings invalidates the exact count.
The content preview is continuous HTML: check the saved PDF for actual page breaks.
In the browser preview, use Print / Save as PDF; its page total is an estimate.

EPUB, DOCX, AI, sync, and collaboration are not included. See README.md
for the feature list and limitations, and VALIDATION.md for testing evidence.

The executable is unsigned.

Google Docs paste keeps supported fonts, sizes, bold, and spacing.
If an earlier paste lost its formatting, select it and paste from the
original document again after opening this version. HTML and CodeBook
project exports keep visual styles; Markdown keeps text structure.
